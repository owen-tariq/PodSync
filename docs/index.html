Features

Everything iTunes did. Plus everything it didn't.

PodSync writes the iPod's own database directly via libgpod, so everything shows up in the device's native menus — no hacks, no re-flashing.

🖱️

Drag & drop syncing

Drop files or whole folders onto the iPod. A sync plan shows exactly what will be added, converted, or skipped as a duplicate — before anything is written.

🎙️

Full podcast manager

Browse the Top 25 chart for your country, search the directory, or paste any RSS feed. Download episodes and sync them into the iPod's Podcasts menu with dates, descriptions, and unplayed dots.

🧹

Podcast retention

Keep only the latest N episodes of each show on the device. Old episodes are removed automatically when new ones sync.

🎛️

Auto mixes

Daily genre mixes, least-played rediscovery, most-played rotation, decade mixes, and per-artist mixes — built locally from your iPod's own play counts and ratings, refreshed every day. No account, no cloud.

📝

Playlists & smart playlists

Create playlists on the device, or define rule-based smart playlists (artist, genre, year, rating, play count) that materialize onto the iPod. Back up all playlists and ratings to a JSON file and restore them anywhere.

🔄

Format conversion

FLAC, WAV, and AIFF convert to AAC with the system encoder — nothing to install. Add ffmpeg and OGG, Opus, WMA input and MP3 output work too, at 320/256/128 kbps.

🖼️

Artwork tools

Covers show right in the track list, missing ones are flagged, and one click fixes them all via cover lookup. Big 2000×2000 covers are downscaled to a size you choose before syncing.

✏️

Metadata editing

Edit title, artist, album, genre, year, rating, and artwork on device tracks — including batch edits across a whole selection. Untagged "Artist - Title" filenames are parsed automatically during sync.

📊

Stats & maintenance

Listening stats from real play counts, an iTunes-style storage bar, a duplicate finder that keeps the best copy, a library ↔ iPod diff view, and Last.fm scrobbling of everything you played on the go.

Install

Running in under a minute.

Requirements: macOS 13 or later (Apple Silicon), a classic click-wheel iPod over USB. Optional: brew install ffmpeg for OGG/Opus/WMA input and MP3 output.

1

Download the DMG

Grab PodSync.dmg from the latest release.

2

Drag to Applications

Open the DMG and drag PodSync into your Applications folder.

3

Clear the Gatekeeper flag

PodSync is open source and not signed with a paid Apple certificate, so run this once in Terminal:

xattr -cr /Applications/PodSync.app
4

Plug in your iPod

Connect it over USB so it mounts as a drive. PodSync detects it automatically and loads its library.

iPod not detected? Make sure it appears in Finder first, try another cable or port, and close iTunes/Music if it grabbed the device. Always use PodSync's Eject button before unplugging.

FAQ

Questions, answered.

macOS says the app "can't be verified" or may contain malware. Is it safe?
Yes — that warning appears for any app not signed with a paid Apple Developer certificate, which open-source projects often skip. PodSync's full source code is public on GitHub and every release is built automatically by GitHub's own servers from that code. Clear the warning once with xattr -cr /Applications/PodSync.app.
Which iPods are supported?
Classic click-wheel iPods that mount as a USB drive: iPod Classic (tested on 7th gen), iPod Video, Nano, and Mini. iPod Touch and iPhone use a different sync protocol and are not supported.
Do I need iTunes installed?
No. PodSync reads and writes the iPod's iTunesDB directly via libgpod, so it works completely standalone. It coexists fine with an iPod that was previously synced by iTunes.
How do the Auto Mixes work — is it random?
Not random. Your iPod records a play count every time you listen; PodSync reads those back along with your star ratings. Daily mixes cluster your genres weighted by what you actually play, On Repeat is literally your most-played, and Discover Weekly resurfaces songs you've barely touched. The selection refreshes daily with a deterministic shuffle. Everything is computed on your Mac — no account, no cloud.
Can it play FLAC on my iPod?
iPods can't play FLAC natively, so PodSync converts it: FLAC, WAV, and AIFF become AAC using macOS's built-in encoder, at a bitrate you pick (320/256/128 kbps). Install ffmpeg (brew install ffmpeg) and OGG, Opus, and WMA input plus MP3 output work too.
Where do podcasts come from?
The charts and search use Apple's public podcast directory; episode downloads come straight from each show's own RSS feed. You can also subscribe to any raw RSS URL. Synced episodes land in the iPod's native Podcasts menu with proper dates, descriptions, and unplayed indicators.
Will PodSync mess up my existing library?
PodSync only writes when you sync, edit, or delete — browsing is read-only. Before large drops it shows a sync plan you confirm. Deleting a playlist never deletes its songs. And you can export all playlists and ratings to a JSON backup at any time.
My iPod isn't detected. What do I check?
The iPod must mount as a disk: check it appears in Finder, enable "disk use" if it was iTunes-managed, try another cable or USB port, and quit iTunes/Music if it auto-opened. PodSync looks for the iPod_Control folder on any mounted volume.
Does it send my data anywhere?
No telemetry, no account, no ads. Network access is only used for the features you invoke: podcast feeds and charts, cover-art lookup, and optional Last.fm scrobbling with your own credentials.
Can I contribute or report a bug?
Please do — the project lives at github.com/owen-tariq/PodSync. Open an issue for bugs or ideas; pull requests are welcome. Every push is built and tested by CI on a real macOS runner.
